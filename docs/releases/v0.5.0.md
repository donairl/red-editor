# Red Text Editor v0.5.0

Changes since v0.4.4.

## New

- **Color themes.** Choose a theme from **View → Theme**: System (follows the OS), Light Modern, Dark Modern, Solarized Light, Solarized Dark, Ocean Dark, Mocha Dark or Eighties Dark. A theme recolors syntax highlighting together with the tab bar, Activity Bar, Explorer, line numbers, console, menus, dialogs and the Markdown preview. Switching takes effect at once, with no restart, and the choice is remembered.
- **Open Recent.** **File → Open Recent** lists the last 20 files and folders you opened, newest first, each with its folder beside it. Long names are shortened to fit the menu. An entry that no longer exists is removed when you pick it. **Clear Recently Opened** empties the list. The list is kept across restarts.
- **New Window.** **File → New Window** (`Ctrl+Shift+N`) starts a second, independent copy of the editor.

## Fixed

- Syntax highlighting in dark mode used a light theme's colors, which read poorly on the dark editor. Dark themes now highlight with dark syntax colors.

## Interface languages

All new text is translated into English, Indonesian, Spanish, German and Chinese.
