# Red Text Editor v0.4.4

Changes since v0.3.0. Version 0.4.0 was never tagged, so its changes are included here.

## New

- **Line bookmarks.** Right-click a line in the editor and choose **Add Bookmark** or **Remove Bookmark**. Bookmarked lines get a marker in the gutter and move with their line as you edit. A **Bookmarked: N** badge in the status bar opens the list of bookmarked lines; click one to jump to it. Bookmarks last until the app is closed.
- **Integrated console.** Open a terminal panel below the editor from **Console** in the Activity Bar, **View → Console**, or `` Ctrl+` ``. It runs your shell with full colour and 5,000 lines of scrollback. While the console has focus, every key goes to the shell. Hiding the panel keeps the shell running.
- **SQL highlighting.** `.sql` files open with SQL highlighting. SQL inside string literals is also coloured in Rust, C, C++, PHP, JavaScript, TypeScript, Go and Python, including multi-line strings. Ordinary text such as `"Select a file"` stays a plain string.
- **File-name filter in the Explorer.** Type in the field under the folder header to list matching files anywhere in the folder. For example, `SMS keluar` finds `SMSForm.php`, `SMSLog.php` and `SMSSender.php`. A new **Search** button in the folder header opens Find in Files.
- **Caret position in the status bar.** The right end of the status bar shows `Ln 12, Col 5`.
- **Detects files changed by other programs.** A file with no unsaved edits reloads by itself when another program changes it. A file with unsaved edits is never replaced without asking: you choose **Reload** or **Keep Mine**. Saving over a file that changed on disk asks first.
- **Editor right-click menu** with Cut, Copy and Paste. Right-clicking inside a selection keeps it.
- **Help → Home** opens the project page.

## Fixed

- **Edit → Copy** and **Edit → Cut** now work on the selection. Before, opening a menu dropped the selection, so they had nothing to act on.
- The selection stays visible while a menu is open and comes back when the menu closes.

## Interface languages

All new text is translated into English, Indonesian, Spanish, German and Chinese.
