# Red Text Editor v0.7.7

Changes since v0.7.0.

## New

- **Git Graph** (**View → Git Graph**, `Ctrl+Alt+G`, or the graph icon in the Source Control title bar). Every branch and tag as a commit graph in place of the editor, 200 commits at a time, with coloured lanes, branch and tag chips (the checked-out branch outlined), author, age and short hash.
  - Click a commit for its message, parents (click one to jump to it) and files; a file opens its diff in the panel beside the graph.
  - Right-click a commit for **Checkout Commit**, **Create Branch Here…** and **Copy Hash**; right-click a branch chip for **Switch to Branch**, **Delete Branch…** (fully merged branches only) and **Copy Name**. Checkout and delete ask first.
  - The graph reloads when HEAD or a branch moves and after fetch, pull or push; the selection survives a reload. `×` or `Esc` returns to the editor.
- **Start page.** The editor opens on a page with **New File**, **Open File…** and **Open Folder…** and your recent folders and files; click one to reopen it. Closing the last tab, or Close All, brings the page back. New File from the page gives one Untitled tab.
- **About dialog** and **Find in Files** panel redesigned.

## Changed

- The commit log records parent hashes; `git log` is read with `%P`.
- The Source Control title bar has a fourth icon, Git Graph, and its title is clipped before the icons in long translations.
- Save, Save As, Find, Replace and Go to Line are ignored while the start page shows; editor-only shortcuts are ignored while the Git Graph shows.

## Under the hood

- `src/git_graph.rs`: a pure, incremental lane layout (unit-tested) and the egui view. The worker keeps a second log for the graph with a generation counter and page dedupe, and caches commit details and files with explicit loading slots.
- `src/welcome.rs`: the start page view, returning actions for `app.rs` to run.
- Branch names passed to `git branch` are guarded with `--`.
- Five new UI strings for the start page and sixteen for the graph, in all five languages.
