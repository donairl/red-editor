# Red Text Editor v1.0.1

Changes since v1.0.0.

## Added

- **File → New File…** creates a file in the folder of the active file, or in the workspace root when the active tab has no file inside the workspace. It opens the Explorer's name field there (showing the Explorer if it was hidden); Enter creates the file and opens it in a tab. The item is disabled when no folder is open.

## Under the hood

- 777 tests, up from 775 in v1.0.0.
