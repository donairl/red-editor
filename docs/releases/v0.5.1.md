# Red Text Editor v0.5.1

Changes since v0.5.0. Windows fixes only.

## Fixed

- **Moving the window between monitors with different display scales.** With two monitors at different scales (for example 100% and 150%), the window stopped at the edge of the first monitor and could not be moved onto the second, by dragging or with Win+Shift+Arrow. The cause was in winit 0.30.13, which picked the wrong monitor when the scale changed and pushed the window back. The editor now ships a patched copy of winit until an upstream release fixes it.
- **No console window.** Starting the `.exe` opened an empty console window beside the editor. Only the editor window opens now.
- **Prettify no longer flashes console windows** when it runs an installed formatter such as `rustfmt`, `ruff` or `prettier`.
