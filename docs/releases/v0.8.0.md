# Red Text Editor v0.8.0

Changes since v0.7.9.

## Added

- **Command Palette** (`Ctrl+Shift+P`) runs any editor command or theme by name, and **Quick Open** (`Ctrl+P`) opens any file in the open folder by name, both with fuzzy matching. View → Command Palette… and File → Quick Open….
- **File operations in the Explorer.** Right-click a file, a folder or the empty space below the tree for **New File**, **New Folder**, **Rename**, **Delete** and **Reveal in Folder**. Names are typed inline in the tree; Enter or a click elsewhere commits, Escape cancels, and a name that is taken or invalid is explained below the field. Delete asks first and moves the entry to the system Trash. Open tabs follow a rename or a move; a deleted file's tab closes unless it has unsaved changes.
- **Auto-indent and auto-close.** Enter keeps the line's indentation, one level deeper after `{` `(` `[`, and Enter between `{}` puts the closer on its own line. Brackets and quotes get their partner, wrap a selection, and are stepped over when typed again; Backspace removes an empty pair; `}` on a blank line outdents. The indent unit follows the document (tabs or its number of spaces). Works with an input method (fcitx, ibus) running.
- **Bracket matching.** The bracket at the caret and its partner get a thin box; `Ctrl+Shift+\` (Edit → Go to Bracket) jumps between them.
- **Code folding** by indentation. Chevrons in the gutter fold and unfold a block, a `⋯` marker after a folded line unfolds it, and View → Fold (`Ctrl+Shift+[`), Unfold (`Ctrl+Shift+]`), Fold All and Unfold All are in the menu and the palette. The caret skips folded blocks; find, Go to Line and Go to Symbol unfold the block they land in.
- **Restore session.** The editor reopens the folder, the saved tabs and the active tab of the last run.
- **Search in the Activity Bar.** A magnifying glass between the Explorer and Source Control opens and closes Find in Files.
- **Git Log panel**, icon buttons to hide the Console and end its shell, **Copy Path** in the tab context menu, and hidden files listed in the Explorer.
- The About → Shortcuts page lists the new shortcuts.

## Changed

- Opening a folder resets the tabs and the search.
- Menus print `Ctrl+Shift+\`, `[` and `]` instead of key names.

## Under the hood

- `src/app.rs` split into `shortcuts.rs`, `menus.rs`, `status_bar.rs`, `console_panel.rs` and `editor_view.rs` (7,092 → about 4,800 lines).
- New pure, tested modules: `file_ops` (name checks, create, rename that never overwrites, Trash, reveal), `auto_edit`, `brackets`, `folding`, `palette`, `session`.
- New dependency: `trash` 5.
