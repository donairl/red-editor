# Red Text Editor v0.7.9

Changes since v0.7.8.

## Added

- **Bash syntax highlighting.** `*.sh`, `*.bash`, `*.zsh` and `*.bats` files, and extension-less shell rc files such as `.bashrc`, `.zshrc` and `.profile`, are coloured with the bundled Bourne Again Shell grammar. Tabs show an `SH` badge, and **Bash** is in the language menu.
- **Line editing shortcuts**, in the Edit menu and on the About → Shortcuts page:
  - `Alt+Up` / `Alt+Down` moves the current line, or the selected lines, up or down.
  - `Shift+Alt+Up` / `Shift+Alt+Down` copies them up or down.
  - `Ctrl+Shift+K` deletes them.
  - `Ctrl+/` toggles the line comment in the document's language: `//`, `#` or `--` where the language has one, otherwise wrapping each line in its block markers (`<!-- -->`, `/* */`, `{{-- --}}`, `{# #}`, `{* *}`). Plain text reports that it has no comment syntax.
  - `Ctrl+D` selects the word at the caret, then on each further press its next occurrence, wrapping to the top.
  - `Shift+Alt+F` formats the document, as a second key for Prettify (`Ctrl+Shift+I` still works).

## Changed

- Markdown preview heading navigation moved from `Alt+Up` / `Alt+Down` to `Ctrl+Alt+Up` / `Ctrl+Alt+Down`, so `Alt` alone moves lines as in other editors.
- Menus and the Shortcuts page print `Ctrl+/` and `` Ctrl+` `` instead of `Ctrl+Slash` and `Ctrl+Backtick`.

## Under the hood

- A `line_ops` module holds the line commands as pure functions over `char` indices, returning the text and the selection the editor shows next, with unit tests for each command, multi-line selections, block edges and non-ASCII text.
