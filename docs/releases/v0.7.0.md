# Red Text Editor v0.7.0

Changes since v0.6.0.

## New

- **Git integration.** The editor runs the `git` on your `PATH`, so your credential helper, ssh-agent and config apply; without git, or outside a repository, nothing changes.
  - **Status bar**: the branch, `*` when files changed, and `↓behind ↑ahead` against the upstream. Click it to switch to another branch, create one, or fetch, pull and push.
  - **Explorer**: changed files are coloured and marked `M` `A` `U` `D` `R` `C`; folders holding changes get a dot.
  - **Gutter**: lines that differ from the last commit get a bar (green added, blue modified) and a red triangle marks removed lines. Markers follow your typing.
  - **Source Control view** (third Activity Bar item, `Ctrl+Shift+G`, View menu): commit box (`Ctrl+Enter`), **Staged Changes**, **Changes** and **Merge Changes** lists with open, stage, unstage and discard buttons on hover, **Pull**, **Push** and **Refresh** in the title, and a badge counting changed files. Discarding, and committing with nothing staged, ask first. A folder that is not a repository offers **Initialize Repository**.
  - **Diff panel**: click a file in Source Control to open it with its changes beside the editor; click a diff line to jump there.
  - **Commit log**: a **COMMITS** section lists the branch's history 100 commits at a time. A commit unfolds into its files; a file shows what the commit did to it in the diff panel, with **Restore This Version**. Each row has a **Checkout** button (detached HEAD). Both ask first.
  - **File History** in the tab and Explorer right-click menus filters the log to one file.
  - **Blame** (**View → Git Blame**, `Ctrl+Alt+B`): a column beside the line numbers names who last changed each line and how long ago; hover for the commit.
  - Git never prompts inside the editor: a pull or push that needs a password or key points to the Console, and a pull refused because the branch diverged says to merge or rebase there.

## Changed

- `Ctrl+B` now hides and restores whichever sidebar view was last shown, Explorer or Source Control.

## Under the hood

- New dependency `similar` for the gutter's line diff. External formatters and git share one process runner (`process.rs`) with a timeout.
