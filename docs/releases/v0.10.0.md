# Red Text Editor v0.10.0

Changes since v0.9.0.

## Added

- **Agent panel** (`Ctrl+Shift+A`, View → Agent Panel, Command Palette): chat with any coding agent that speaks the [Agent Client Protocol](https://agentclientprotocol.com) from a panel on the right. Set the command in Settings → Agent (for example `npx @zed-industries/claude-code-acp` or `gemini --experimental-acp`); Red bundles no agent. Replies stream in, **Stop** cancels a turn, **New Session** starts over, **Restart Agent** restarts the process, and sign-in requests from the agent are shown in the panel.
- **Tool-call cards and plan.** Each tool call is a card with its kind, status, details, diffs and links to the files it touched. Permission requests show the agent's options on the card; the agent's plan appears as a checklist.
- **Agent edits land in your buffers, unsaved.** The agent reads and writes files through the open tabs, inside the workspace only. A card shows an unsaved badge with **Diff** and **Save**; **Save All Agent Edits** sits in the panel header.
- **Terminals for the agent.** Commands the agent runs show live output inside the tool card. They are stopped on New Session, Restart and exit.
- **Context for prompts.** Type `@` or click the `@` button to attach a file as a removable chip. **Add Selection to Agent** (`Ctrl+Shift+L`, editor right-click menu, Command Palette) attaches the selected lines with their path and line range (up to 256 KB).
- **Several Console terminals.** `Ctrl+Shift+\`` opens another shell tab in the Console panel, labelled Terminal N, each stopped on its own.
- The Agent panel strings are translated in Indonesian, Spanish, German and Chinese.

## Known limitations

- On Windows, type `npx.cmd` in the agent command; `npx` alone is not found. The agent's process tree is only killed while its direct child is running.
- Agent terminals are pipes, not a PTY.
- Editor shortcuts such as `Alt+Up` and `Ctrl+/` still act on the document while the agent prompt has focus.

## Under the hood

- New modules: `acp` (transport, client state machine, model, fs, terminals, context), `agent_panel`, `agent_cards`, `agent_edits`, `agent_settings`, plus a scripted fake ACP agent used by the tests.
- `app.rs` was split further: `disk.rs` (polling and reloading on disk changes) and `git_actions.rs` (git polling, SCM and Git Graph actions, hunk popup, diff view) moved out, along with the earlier `shortcuts`, `menus`, `status_bar`, `console_panel` and `editor_view`. No behaviour change.
- 769 tests, up from 674 in v0.9.0.
- A clippy warning in the Console panel tests is fixed.
- CI now takes the GitHub release body from `docs/releases/<tag>.md`.
