# Red Text Editor v0.9.0

Changes since v0.8.0.

## Added

- **Settings** (`Ctrl+,`, File → Settings…, Command Palette): one window for tab size, insert spaces, trim trailing whitespace on save and format on save. It also holds font size, theme, indent guides, render whitespace, auto save and the interface language, which still work from their menus as well. Trimming and formatting run on an explicit save only, never on auto-save. When the formatter fails, the file is still saved and the status bar says why.
- **Tab / Shift+Tab** indent and outdent. With a caret, Tab inserts one indent level; with a selection over several lines, every line gets one. Shift+Tab takes one level off each line. A document keeps the indentation it already has; the tab size and spaces settings apply to files with no indented line yet. egui always draws a tab character four columns wide.
- **Side-by-side diff view** (`Ctrl+Shift+D`, View → Compare with HEAD / Compare with File…): the active document, unsaved edits included, beside HEAD's copy or another file, in place of the editor. Up and Down step between changes, a double click jumps to the line, Escape closes.
- **Gutter hunk popup.** Click a git change marker to see the lines as HEAD has them and as they are now. **Revert Change** puts the old lines back in the editor (unsaved); **Stage Change** stages only that hunk, leaving the work tree alone.
- **Split editor** (`Ctrl+\`, View → Split Editor): the same document in two views side by side. Each view has its own caret and scroll; typing goes to the one with the keyboard and shows in both.
- **Font zoom** (`Ctrl++` / `Ctrl+-` / `Ctrl+0`, `Ctrl` + scroll, View → Zoom): one font size for the editor, the gutter, the diff view and the terminal, kept across restarts. The status bar shows it as a percentage when it is not the default.
- **Indent guides** (View → Indent Guides, on by default): a thin line at each indentation level. Wrapped and folded lines are skipped.
- **Render whitespace** (View → Render Whitespace): a faint dot for every space and an arrow for every tab.
- **Auto Save** (File → Auto Save, off by default, kept across restarts): every file with a path saves itself after a one-second pause in the typing, and when the window loses focus. A file another program changed is left to the conflict dialog.
- **Drag and drop**: files dropped on the window open in tabs; a dropped folder becomes the workspace. A hint covers the window while files hover it. On Linux this needs X11: winit has no drag and drop on Wayland yet.
- **Code navigation for more languages.** Go to Symbol (`Ctrl+R`), Go to Definition (`F12`) and Find References (`Shift+F12`) now know JavaScript / TypeScript and C / C++, beside Rust, PHP, Go and Python. Markdown files get their headings in Go to Symbol.

## Changed

- **Restore session** reopens every tab at the caret and scroll position it was left at. Sessions saved by older versions still load, at the top of each file.
- A file opens with the caret at its start, not past its end.
- Opening a folder closes the diff view along with the tabs it belonged to.
- `Ctrl++` and `Ctrl+-` no longer zoom the whole window: they drive the editor's font size instead.

## Under the hood

- New modules: `diff_view`, `zoom`, `drop`, `indent_guides`, `whitespace`, `settings`, `settings_window`.
- `session` stores a caret and a scroll offset per tab, reading the old path-only format too.
- `symbols` gains scanners for JavaScript / TypeScript, C / C++ and Markdown, and `navigates` keeps Go to Definition code-only.
- 674 tests, up from 552 in v0.8.0.
