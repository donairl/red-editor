# Red Text Editor v0.7.8

Changes since v0.7.7.

## Fixed

- **Git Blame showed an empty column.** The column sits left of the editor's scroll area but was painted through the scroll area's clip rect, which ends where the column begins, so the `author · age` labels and the loading note were never visible. The column now paints through its own clip rect, and hovering a line for the commit's hash and summary works too.

## Under the hood

- The blame test checks that the painted labels' clip rects contain them, so a clipped-away column fails the test.
