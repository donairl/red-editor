# Red Text Editor v0.6.0

Changes since v0.5.1.

## New

- **Code navigation for Rust, PHP, Go and Python.**
  - **Go to Symbol** (Ctrl+R, Edit menu): a bar above the editor lists the functions, methods, structs, classes, traits, interfaces, enums, constants and so on that the document defines. Type to filter, Up/Down to pick, Enter to jump.
  - **Go to Definition** (F12, Ctrl+click, Edit and right-click menus): jumps to the definition of the name under the caret. It looks in the document first, then in the open folder's files of the same language. A single match opens directly; several are listed in the Find in Files panel.
  - **Find References** (Shift+F12): lists every whole-word use of the name in the open folder, in the Find in Files panel.
  - Definitions are found by a light scanner, not a full parser: nesting follows indentation, and same-named symbols (such as `new` in several structs) are all offered.
- **Navigation in the Markdown preview.** A bar above the preview has previous/next heading buttons (also Alt+Up / Alt+Down) and an outline of every heading. Picking a heading or clicking an `#anchor` link scrolls the preview there and moves the editor to that line. Anchors follow GitHub: `## Getting Started` is `#getting-started`.
- **Whole Word** toggle in Find in Files.

## Improved

- **Big projects stay responsive.** Opening a folder with many large files no longer freezes the editor. The editor keeps its layout between frames instead of laying out the whole file again, line counting is faster, and the Explorer lays out only the rows in view. The Explorer filter indexes files in the background and shows matches as they arrive.
- Files over 10 MB are refused when opened or reloaded.
