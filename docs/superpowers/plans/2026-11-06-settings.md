# Settings Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Settings window (`Ctrl+,`) with four new editor settings (tab size, insert spaces, trim trailing whitespace on save, format on save) plus the existing toggles, and Tab / Shift+Tab indent and outdent.

**Architecture:** `src/settings.rs` holds a `Copy` struct `EditorSettings`, stored as JSON under one eframe key. The struct reaches the editor through `EditorRequest`, so `auto_edit::apply_events` can use it for its fallback indent and for Tab / Shift+Tab. Explicit saves go through a new `prepare_for_save` (trim, then `prettify`). Auto-save skips it. `src/settings_window.rs` draws a non-modal `egui::Window` that edits the same app fields the menus edit.

**Tech Stack:** Rust 2024, eframe/egui 0.37, serde_json.

Spec: `docs/superpowers/specs/2026-11-06-settings-design.md`.

**Conventions (read before starting):**
- Pure functions use `char` indices, in the style of `src/line_ops.rs` and `src/auto_edit.rs`. They return `line_ops::Edit { text, selection }`.
- Doc comments are full sentences explaining *why*. Match the tone of the surrounding code.
- Unit tests live in a `#[cfg(test)] mod tests` at the bottom of each file.
- Before each commit, run `cargo test` (all must pass) and `cargo clippy --all-targets` (no new warnings).
- User-visible strings go through i18n (`self.i18n.t("key")`). Every new key must be added to **all** of `assets/lang/{en,id,de,es,zh}.json`. `i18n.rs` has `test_builtin_languages_have_the_same_keys` and `test_every_key_used_in_code_exists`, which enforce this.

```rust
//! The editor settings the Settings window edits: indentation and what an
//! explicit save does to the text. Kept in eframe's storage as one JSON
//! object; anything unreadable falls back to the defaults, field by field.

use serde_json::{Value, json};

/// Fewest and most spaces one indent level may be.
pub const MIN_TAB_SIZE: u8 = 1;
pub const MAX_TAB_SIZE: u8 = 8;

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub struct EditorSettings {
    /// Spaces per indent level when `insert_spaces` is on. egui always draws
    /// a `\t` four columns wide, so this is not the width of a tab.
    pub tab_size: u8,
    /// Indent with spaces, or with one `\t` per level.
    pub insert_spaces: bool,
    /// Strip spaces and tabs at line ends on an explicit save.
    pub trim_trailing_whitespace: bool,
    /// Run the document's formatter on an explicit save.
    pub format_on_save: bool,
}

impl Default for EditorSettings {
    fn default() -> Self {
        Self {
            tab_size: 4,
            insert_spaces: true,
            trim_trailing_whitespace: false,
            format_on_save: false,
        }
    }
}

impl EditorSettings {
    /// One indent level: `"\t"`, or `tab_size` spaces.
    pub fn indent_unit(&self) -> String {
        if self.insert_spaces {
            " ".repeat(usize::from(self.tab_size))
        } else {
            "\t".to_owned()
        }
    }

    /// The settings as eframe's storage keeps them.
    pub fn to_storage(&self) -> String {
        json!({
            "tab_size": self.tab_size,
            "insert_spaces": self.insert_spaces,
            "trim_trailing_whitespace": self.trim_trailing_whitespace,
            "format_on_save": self.format_on_save,
        })
        .to_string()
    }

    /// Reads what [`Self::to_storage`] wrote. A missing or unreadable text
    /// gives the defaults; so does each field that is missing or of the
    /// wrong type. `tab_size` is clamped into range.
    pub fn from_storage(text: Option<&str>) -> Self {
        let defaults = Self::default();
        let Some(Value::Object(map)) = text.and_then(|t| serde_json::from_str(t).ok()) else {
            return defaults;
        };
        let flag = |key: &str, default: bool| map.get(key).and_then(Value::as_bool).unwrap_or(default);
        let tab_size = map
            .get("tab_size")
            .and_then(Value::as_i64)
            .map(|n| n.clamp(i64::from(MIN_TAB_SIZE), i64::from(MAX_TAB_SIZE)) as u8)
            .unwrap_or(defaults.tab_size);
        Self {
            tab_size,
            insert_spaces: flag("insert_spaces", defaults.insert_spaces),
            trim_trailing_whitespace: flag("trim_trailing_whitespace", defaults.trim_trailing_whitespace),
            format_on_save: flag("format_on_save", defaults.format_on_save),
        }
    }
}
```

```rust
/// The `char` index where each line of `chars` starts.
fn line_starts(chars: &[char]) -> Vec<usize> {
    let mut starts = vec![0];
    starts.extend(chars.iter().enumerate().filter(|(_, c)| **c == '\n').map(|(i, _)| i + 1));
    starts
}

/// The line `pos` is on.
fn line_of(starts: &[usize], pos: usize) -> usize {
    starts.partition_point(|&s| s <= pos) - 1
}

/// The first and last line a block indent or outdent acts on. A last line
/// the selection reaches only at its column 0 is left out, as in VS Code:
/// selecting whole lines ends there.
fn touched_lines(starts: &[usize], (a, b): Range) -> (usize, usize) {
    let first = line_of(starts, a);
    let mut last = line_of(starts, b);
    if last > first && starts[last] == b {
        last -= 1;
    }
    (first, last)
}

/// Tab: with a caret or a selection inside one line, `unit` replaces the
/// selection; a selection across lines gets `unit` in front of every line it
/// touches and grows to keep covering the same text.
pub fn indent(text: &str, selection: Range, unit: &str) -> Option<Edit> {
    let chars: Vec<char> = text.chars().collect();
    let (a, b) = sorted(&chars, selection);
    let starts = line_starts(&chars);
    if line_of(&starts, a) == line_of(&starts, b) {
        return Some(plain_insert(text, (a, b), unit));
    }
    let (first, last) = touched_lines(&starts, (a, b));
    let mut out = String::with_capacity(text.len() + unit.len() * (last - first + 1));
    let mut next = first;
    for (i, c) in chars.iter().enumerate() {
        if next <= last && i == starts[next] {
            out.push_str(unit);
            next += 1;
        }
        out.push(*c);
    }
    let n = unit.chars().count();
    let shift = |p: usize| p + n * (first..=last).filter(|&l| starts[l] <= p).count();
    Some(Edit { text: out, selection: (shift(a), shift(b)) })
}

/// Shift+Tab: every line the caret or selection touches loses one level from
/// its front — one `\t`, or up to `width` spaces. `None` when no line has
/// any indentation to lose.
pub fn outdent(text: &str, selection: Range, width: usize) -> Option<Edit> {
    let chars: Vec<char> = text.chars().collect();
    let (a, b) = sorted(&chars, selection);
    let starts = line_starts(&chars);
    let (first, last) = touched_lines(&starts, (a, b));
    // (line start, chars removed) for each line that loses indentation.
    let cuts: Vec<(usize, usize)> = (first..=last)
        .filter_map(|line| {
            let rest = &chars[starts[line]..];
            let cut = if rest.first() == Some(&'\t') {
                1
            } else {
                rest.iter().take_while(|&&c| c == ' ').take(width.max(1)).count()
            };
            (cut > 0).then_some((starts[line], cut))
        })
        .collect();
    if cuts.is_empty() {
        return None;
    }
    let mut out = String::with_capacity(text.len());
    let (mut i, mut k) = (0, 0);
    while i < chars.len() {
        if k < cuts.len() && i == cuts[k].0 {
            i += cuts[k].1;
            k += 1;
            continue;
        }
        out.push(chars[i]);
        i += 1;
    }
    let shift = |p: usize| {
        p - cuts.iter().map(|&(s, cut)| if s <= p { cut.min(p - s) } else { 0 }).sum::<usize>()
    };
    Some(Edit { text: out, selection: (shift(a), shift(b)) })
}
```

```rust
/// The text with spaces and tabs removed from the end of every line, `\r\n`
/// endings kept; `None` when there is nothing to remove.
pub fn trim_trailing_whitespace(text: &str) -> Option<String> {
    let mut out = String::with_capacity(text.len());
    let mut lines = text.split('\n').peekable();
    while let Some(line) = lines.next() {
        let (body, cr) = match line.strip_suffix('\r') {
            Some(body) => (body, "\r"),
            None => (line, ""),
        };
        out.push_str(body.trim_end_matches([' ', '\t']));
        out.push_str(cr);
        if lines.peek().is_some() {
            out.push('\n');
        }
    }
    (out != text).then_some(out)
}
```

```rust
    /// What an explicit save does to the text first, by the editor
    /// settings: trim trailing whitespace, then run the formatter. The tab's
    /// text is changed in place so the editor shows what gets written.
    /// Returns a warning for the status bar when the formatter failed; the
    /// file is then saved as it is. Auto-save never calls this: it would
    /// strip a space the user just typed.
    fn prepare_for_save(&mut self, index: usize) -> Option<String> {
        let settings = self.editor_settings;
        let tab = &mut self.tabs[index];
        if settings.trim_trailing_whitespace
            && let Some(text) = line_ops::trim_trailing_whitespace(&tab.text_content)
        {
            tab.text_content = text;
        }
        if !settings.format_on_save {
            return None;
        }
        let language = tab.effective_language();
        if !prettify::supports(language) {
            return None;
        }
        match prettify::prettify(language, &tab.text_content) {
            Ok(text) => {
                if text != tab.text_content {
                    tab.text_content = text;
                }
                None
            }
            Err(error) => Some(self.i18n.tf("msg.prettify_failed", &[("error", &error)])),
        }
    }
```

```rust
//! The Settings window: the editor settings and the toggles that also live
//! in the menus, in one place. Every control edits the same app field its
//! menu edits, so the two always agree; a change applies at once and is
//! kept with the rest of eframe's storage.

use eframe::egui;

use crate::app::TextEditorApp;
use crate::settings::{MAX_TAB_SIZE, MIN_TAB_SIZE};
use crate::theme::ThemeId;
use crate::zoom;

impl TextEditorApp {
    /// Draws the window while `show_settings` is on; its close button turns
    /// it off.
    pub fn show_settings_window(&mut self, ctx: &egui::Context) {
        if !self.show_settings {
            return;
        }
        let mut open = true;
        egui::Window::new(self.i18n.t("settings.title").to_owned())
            .open(&mut open)
            .collapsible(false)
            .resizable(false)
            .show(ctx, |ui| self.settings_contents(ui));
        self.show_settings = open;
    }

    fn settings_contents(&mut self, ui: &mut egui::Ui) {
        ui.heading(self.i18n.t("settings.editor"));
        egui::Grid::new("settings_editor").num_columns(2).show(ui, |ui| {
            ui.label(self.i18n.t("settings.tab_size"));
            ui.add(egui::DragValue::new(&mut self.editor_settings.tab_size).range(MIN_TAB_SIZE..=MAX_TAB_SIZE));
            ui.end_row();
        });
        let s = &mut self.editor_settings;
        ui.checkbox(&mut s.insert_spaces, self.i18n.t("settings.insert_spaces"));
        ui.checkbox(&mut s.trim_trailing_whitespace, self.i18n.t("settings.trim_trailing_whitespace"));
        ui.checkbox(&mut s.format_on_save, self.i18n.t("settings.format_on_save"));

        ui.separator();
        ui.heading(self.i18n.t("settings.appearance"));
        egui::Grid::new("settings_appearance").num_columns(2).show(ui, |ui| {
            ui.label(self.i18n.t("settings.font_size"));
            let mut size = self.font_size;
            if ui
                .add(egui::DragValue::new(&mut size).range(zoom::MIN_SIZE..=zoom::MAX_SIZE).speed(0.5))
                .changed()
            {
                self.font_size = zoom::clamp(size);
            }
            ui.end_row();

            ui.label(self.i18n.t("settings.theme"));
            let name_of = |id: ThemeId, i18n: &crate::i18n::I18n| {
                id.name().map(str::to_owned).unwrap_or_else(|| i18n.t("theme.system").to_owned())
            };
            let current = name_of(self.theme, &self.i18n);
            egui::ComboBox::from_id_salt("settings_theme")
                .selected_text(current)
                .show_ui(ui, |ui| {
                    for id in ThemeId::ALL {
                        let name = name_of(id, &self.i18n);
                        ui.selectable_value(&mut self.theme, id, name);
                    }
                });
            ui.end_row();
        });
        ui.checkbox(&mut self.show_indent_guides, self.i18n.t("view.indent_guides"));
        ui.checkbox(&mut self.show_whitespace, self.i18n.t("view.whitespace"));

        ui.separator();
        ui.heading(self.i18n.t("settings.general"));
        let mut auto_save = self.auto_save;
        if ui.checkbox(&mut auto_save, self.i18n.t("file.auto_save")).changed() {
            // Through the toggle, so its timers reset as the menu's do.
            self.toggle_auto_save();
        }
        egui::Grid::new("settings_general").num_columns(2).show(ui, |ui| {
            ui.label(self.i18n.t("settings.language"));
            let current = self.i18n.code().to_owned();
            let locales: Vec<(String, String)> = self
                .i18n
                .locales()
                .map(|(code, name)| (code.to_owned(), name.to_owned()))
                .collect();
            let current_name = locales
                .iter()
                .find(|(code, _)| *code == current)
                .map(|(_, name)| name.clone())
                .unwrap_or(current.clone());
            egui::ComboBox::from_id_salt("settings_language")
                .selected_text(current_name)
                .show_ui(ui, |ui| {
                    for (code, name) in locales {
                        if ui.selectable_label(code == current, name).clicked() {
                            self.i18n.select(&code);
                        }
                    }
                });
            ui.end_row();
        });
    }
}
```
