# Multi-language UI (i18n) from JSON files in `assets/lang/`

**Date:** 2026-10-17
**Status:** Approved by user
**Project:** `rred_text_editor`

## Context

All UI text is hard-coded in Indonesian across `src/app.rs`, `src/modals.rs`, `src/file_browser.rs`, `src/activity_bar.rs` and `src/highlighter.rs`. The user wants the interface translatable, with each language a JSON file in an `assets/` folder so new languages can be added without recompiling.

User decisions:
- **Source:** `assets/lang/id.json` and `assets/lang/en.json` are embedded in the binary (`include_str!`), so they work after `cargo install`. At start-up, extra `*.json` files are read from `assets/lang/` next to the executable and in the working directory; a file whose code matches a loaded language merges over it key by key.
- **Default:** saved choice, else system locale (`LANG`/`LC_ALL`/`LC_MESSAGES`, e.g. `id_ID.UTF-8` → `id`) when such a language exists, else `en`, else `id`. Choice made in **Tampilan → Bahasa Antarmuka** and remembered across restarts.
- **New documents:** empty buffer with a grey translated placeholder (egui `TextEdit::hint_text`) instead of the literal "Ketik sesuatu di sini..." text.

## JSON format

Flat object of string keys → string values; file stem is the language code (`en.json` → `en`). `"name"` is the language's display name. `{placeholder}` tokens are replaced at runtime.

| Key | id | en |
|---|---|---|
| `name` | Bahasa Indonesia | English |
| `menu.file` / `menu.view` / `menu.help` | File / Tampilan / Help | File / View / Help |
| `menu.syntax` | Bahasa | Language |
| `menu.ui_language` | Bahasa Antarmuka | Interface Language |
| `file.new_tab`, `file.close_tab`, `file.open_file`, `file.open_folder`, `file.save`, `file.save_as`, `file.exit` | Tab Baru, Tutup Tab, Buka File..., Buka Folder..., Simpan, Simpan Sebagai..., Keluar | New Tab, Close Tab, Open File..., Open Folder..., Save, Save As..., Exit |
| `view.word_wrap`, `view.line_numbers` | Bungkus Baris, Nomor Baris | Word Wrap, Line Numbers |
| `help.about` | About | About |
| `toolbar.characters` | Karakter: {count} | Characters: {count} |
| `status.document`, `status.modified` | Dokumen: {name}{modified}, ` [diubah]` | Document: {name}{modified}, ` [modified]` |
| `doc.untitled` | [Dokumen Baru] | [New Document] |
| `editor.placeholder` | Ketik sesuatu di sini... | Type something here... |
| `msg.already_open`, `msg.opened`, `msg.too_large`, `msg.saved`, `msg.folder_opened` | File sudah dibuka. / File berhasil dibuka. / File terlalu besar untuk syntax highlighting. / File berhasil disimpan. / Folder dibuka. | File is already open. / File opened. / File too large for syntax highlighting. / File saved. / Folder opened. |
| `msg.open_failed`, `msg.save_failed` | Gagal membuka file: {error} / Gagal menyimpan file: {error} | Failed to open file: {error} / Failed to save file: {error} |
| `msg.language_load_failed` | Gagal memuat bahasa {file}: {error} | Failed to load language {file}: {error} |
| `about.title`, `about.version`, `about.description`, `about.close` | Tentang Red Text Editor, Versi {version}, Editor teks sederhana dan cepat berbasis Rust & egui., Tutup | About Red Text Editor, Version {version}, A simple, fast text editor built with Rust & egui., Close |
| `unsaved.title`, `unsaved.message` | Perubahan Belum Disimpan, Terdapat perubahan belum disimpan pada "{name}". Simpan sekarang? | Unsaved Changes, "{name}" has unsaved changes. Save now? |
| `unsaved.save`, `unsaved.discard`, `unsaved.cancel` | Simpan, Abaikan, Batal | Save, Don't Save, Cancel |
| `language.plain_text` | Teks Biasa | Plain Text |
| `explorer.title`, `explorer.refresh`, `explorer.collapse_all`, `activity.explorer` | EXPLORER, Muat Ulang, Ciutkan Semua, Explorer | EXPLORER, Refresh, Collapse All, Explorer |

Not translated: product name in the window title (`… - Red Text Editor`), other language names (Rust, C, …), internal io error text.

## Design

### New `src/i18n.rs`
- `I18n { locales: Vec<Locale>, current: usize }`, `Locale { code, name, strings: HashMap<String, String> }`, sorted by display name.
- `I18n::builtin()` — embedded `id` + `en` only, current `id` (used by `TextEditorApp::default()` so existing tests stay Indonesian and deterministic).
- `I18n::load(dirs: &[PathBuf]) -> (I18n, Vec<String>)` — builtin, then every `*.json` in each dir (dirs deduplicated via `canonicalize`); parse with `serde_json::from_str::<HashMap<String, String>>`; bad file → skipped, error text returned.
- `search_dirs()` — `<current_exe dir>/assets/lang`, `<cwd>/assets/lang`.
- `t(&self, key) -> &str` — current locale → `id` → the key itself. `tf(&self, key, &[(&str, &str)]) -> String` replaces `{name}` tokens.
- `select(&mut self, code) -> bool`, `code()`, `locales() -> impl Iterator<Item = (&str code, &str name)>`.
- `choose_initial(&mut self, saved: Option<&str>, system: Option<&str>)` and `system_language() -> Option<String>` (reads `LC_ALL`, `LC_MESSAGES`, `LANG`; strips `_REGION.ENCODING`).

### `Cargo.toml`
- Add `serde_json = "1"` (needs network on first build).
- `eframe = { version = "0.37", features = ["persistence"] }` → `cc.storage` / `App::save` with `Storage::get_string` / `set_string` (key `ui_language`). Side effect: eframe also remembers window size and egui panel state.

### `src/main.rs`
- `mod i18n;`, `Box::new(|cc| Ok(Box::new(TextEditorApp::new(cc))))`.

### `src/app.rs`
- Field `pub i18n: I18n`; `Default` uses `I18n::builtin()`.
- `TextEditorApp::new(cc)`: `I18n::load(&i18n::search_dirs())`, `choose_initial(cc.storage.and_then(|s| s.get_string("ui_language")), system_language())`; first load error goes to `status_message`.
- `impl eframe::App`: `fn save(&mut self, storage)` → `storage.set_string("ui_language", self.i18n.code().to_owned())`.
- Every literal from the table replaced by `self.i18n.t(..)` / `tf(..)` (menus, status bar, toolbar, status messages in `open_file_in_tab`, `load_file`, `save_tab`, `save_as`, `trigger_open_folder`).
- `show_view_menu` gains a `menu.ui_language` submenu listing `locales()` as `selectable_label`s → `select(code)`.
- `show_language_menu` uses `menu.syntax` and shows `language.plain_text` for `Language::PlainText` (new helper `language_label(Language) -> String`; `Language::display_name` stays for the other names).
- `DocumentTab::file_display_name(&self, untitled: &str)` and `tab_view(&self, untitled: &str)` take the translated untitled label; app call sites pass `self.i18n.t("doc.untitled")`.
- Placeholder: remove `INITIAL_TEXT`; `default_new` starts empty; `is_pristine` = no path, not dirty, empty text; `render_editor` gets `hint: &str` and calls `.hint_text(hint)`.

### Other modules
- `src/modals.rs`: `show_about_modal(ctx, open, &I18n)`, `show_unsaved_changes_modal(ctx, name, &I18n)`; version via `env!("CARGO_PKG_VERSION")`.
- `src/file_browser.rs`: `show(ui, explorer, active_file, &I18n)` for title and the two tooltips.
- `src/activity_bar.rs`: `show(ui, explorer_open, tooltip: &str)`.

### Files
- Create: `assets/lang/id.json`, `assets/lang/en.json`, `src/i18n.rs`.
- Modify: `Cargo.toml`, `src/main.rs`, `src/app.rs`, `src/modals.rs`, `src/file_browser.rs`, `src/activity_bar.rs`, `README.md` (section "Menambah bahasa antarmuka": copy `en.json` to `assets/lang/<code>.json`, translate, restart; where the folder is looked up).

## Process
Branch `feat/i18n`; brainstorming spec in `docs/superpowers/specs/` + TDD per task, commits per task; merge on user request.

## Verification
- **`i18n` unit tests:** builtin `id`/`en` parse; `id.json` and `en.json` have exactly the same keys; `t` falls back current → `id` → key; `tf` replaces tokens; `load` from a temp dir adds a new locale, merges an override for an existing code, skips and reports invalid JSON; `choose_initial` precedence (saved > system > `en` > `id`, unknown saved code ignored); `system_language` parses `id_ID.UTF-8`, `en_US`, `C`.
- **Key coverage test:** scan `include_str!` of each `src/*.rs` for `t("…")` / `tf("…"` keys; every key exists in `id.json`.
- **App tests:** existing 101 tests stay green (default `id`); after `i18n.select("en")` the window title reads `[New Document] - Red Text Editor` and the View menu paints `Interface Language`; a fake `eframe::Storage` proves `save` writes `ui_language`; an empty new document paints the placeholder hint; `is_pristine` true for a fresh tab.
- Run `cargo test -- --skip test_save_tab_restores_active_tab_index`, `cargo clippy --all-targets`.
- Manual: `cargo run`, switch Tampilan → Bahasa Antarmuka → English, restart → still English; drop a `assets/lang/xx.json` copy with changed `name`, restart → appears in the menu.
